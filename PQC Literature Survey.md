# PQC Literature Survey

Literature survey for a BSc thesis on post-quantum cryptography and the Harvest Now, Decrypt Later (HNDL) threat, with a testbed comparing classical, hybrid (X25519MLKEM768), and post-quantum key exchange in TLS 1.3 and SSH.

## Repository structure

- `pdfs/`: primary sources (PDF) and official documentation.
- `notes/`: reading notes on the sources used in the thesis.
- `references.bib`: BibTeX entries for all cited sources.

## Notes

Each note explains what the source contains and how I use it in the thesis.
